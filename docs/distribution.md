# Distribution Contract

## Endpoints

- Canonical development source:
  <https://git.dannyhunn.com/gotthboard/gotth-translate>
- Public clone and future releases:
  <https://github.com/gotthboard/gotth-translate>
- Public bug tracker:
  <https://github.com/gotthboard/gotth-translate/issues>
- Private vulnerability reports:
  <https://github.com/gotthboard/gotth-translate/security/advisories/new>

Forgejo pushes one way to GitHub. GitHub does not feed commits or tags back to
Forgejo. A ref is distributed only when the exact object ID is visible at both
endpoints.
